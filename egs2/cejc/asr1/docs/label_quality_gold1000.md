# 人手正解 1000 件によるラベル品質の検証（2026-09-30）

対象: HANDOFF §5.1 / SESSION_HANDOFF §3 の 4 番。
問い: 継続/完了の二値分離 0.65 の壁は、ラベル（Qwen3-8B 付与）の誤りでどこまで説明できるか。

## 結論

**「0.65 の壁」のうち約 0.05 は評価ラベルの誤りによる見かけの低さ。人手正解で測ると音声モデルは約 0.70。**
ただし LLM ラベル自体が人手と 0.74 しか一致しないので、学習目標の質がそのまま天井になっている。

継続/完了の区間、サンプリングの偏り補正後（補正前は括弧内）:

| 比較 | 一致率 |
|---|---|
| LLM ラベル（`data/*/tag`）vs 人手 | **0.742**（0.747） |
| 音声のみ（frame2-blk42）vs 人手 | **0.697**（0.717） |
| 融合（音声 0.55）vs 人手 | 0.692（0.726） |
| 音声のみ vs LLM ラベル（＝従来の測り方） | **0.648**（0.691） |
| 融合 vs LLM ラベル | 0.680（0.722） |

- **音声モデルは LLM の誤りをそのまま覚えてはいない。** LLM ラベルが誤っている区間で、音声のみは人手に 56% 一致
  （コイン投げ以上）。一方、融合は 49% で、BERT（LLM ラベルで学習）が LLM の誤りを引き継いでいる。
- LLM 付与ラベルの F1 0.805 は **「完了」クラスの F1**（Qwen 生出力・1000 件・二値）だった。macro ではない。
  偏り補正後は 完了 F1 0.815 / **継続 F1 0.60** / macro 0.71。**継続ラベルが特に弱い。**
- 現行の `tag` は Qwen3 `full_context/oneshot`（exp27 の PRIMARY）の出力と 91.2% しか一致しない。
  差分は主に Qwen の「完了」→ tag の「継続」（17,576 件）。何らかの後処理が入っているが出所は未確認。
  人手との一致は Qwen 生 0.748 / tag 0.742 と、後処理で良くはなっていない（継続 F1 は 0.604→0.620）。

## 読み方の注意

- **件数が少ない。** 人手正解 1000 件のうち、会話ごと今の ASR データに無い（T/W 系）ものが 388 件、
  対応づかないものが 7 件。使えるのは **605 件**（train_nodup 524 / train_dev 24 / eval 57）。
- **train の 524 件はモデルが学習に使った区間**（LLM ラベルで）。モデルが LLM ラベルに寄る方向の偏りなので、
  「モデル vs 人手」は控えめに出ている。学習外の 81 件だけでも 音声のみ 0.716 / LLM ラベル 0.716 で傾向は同じ。
- **偏り補正は近似。** 抽出は 8 モデルの判定でプール分けされているが、手元にあるのは Qwen fc_os の 1 本だけ。
  そこで層（Qwen の判定 × auto_hai）で事後層別した。層 (完了, auto_hai=True) は母集団 86,955 に対し
  標本 46 件と薄く、重みが大きい。
- 人手正解の母集団は「どのモデルも相槌と判定しなかった区間」。相槌は対象外。
- 音声モデルが相槌と予測した区間は不一致として数えている。

## 含意

1. **評価ラベルを人手寄りにするだけで、見かけの二値分離は約 +0.05。** 論文等で「0.65 で頭打ち」と
   書くなら、人手正解では約 0.70 であることを併記すべき。
2. **モデル（0.70）と LLM ラベル（0.74）の差は 0.04 しかない。** モデル側をいくら改良しても、
   学習目標が 0.74 の品質なら伸びしろは小さい。ラベルの付け直し（特に継続）が最も大きな梃子。
3. 融合のテキスト側（BERT）は LLM の誤りを引き継ぐ。人手正解で見ると融合は音声のみを上回らない
   （0.692 vs 0.697）。LLM ラベルで測った融合の利得（0.7354→0.7537）の一部は、
   **LLM の癖を真似ることによる利得**の可能性がある。
