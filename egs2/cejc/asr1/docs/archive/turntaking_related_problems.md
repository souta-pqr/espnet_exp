# 類似の学習問題の調査：系列の「早期分類」（accuracy–latency トレードオフ）

作成日: 2026-06-16
関連: [turntaking_multitask_method.md](turntaking_multitask_method.md)（本手法）/ [turntaking_status_overview.md](turntaking_status_overview.md)（手法A〜E の地図）

> 目的：本タスク（発話区間末の早期判定）と**同じ構造の学習問題**が他分野にないかを調べ、
> 「どんな問題か」「どんなロジックで学習しているか」を整理する。
> 結論から言うと、これは **「系列の早期分類（early classification of sequences）」** という確立した
> 問題クラスで、時系列・音声・翻訳・推論計算量など複数分野に兄弟問題がある。

---

## 0. 本タスクの抽象化（何と同型か）

- 入力：系列 x_1, x_2, … が**逐次**（streaming）で与えられる。
- 各時刻 t で「いま確定するか / もう少し待つか」を選べる。確定したらクラス（区間末/非区間末/相槌）を出す。
- 目標：**精度を保ちつつ、できるだけ早い t で確定**する。
- 損失の形：`L = 分類誤り + λ · 遅延コスト`（早すぎる誤判定＝分類誤りで罰、遅すぎ＝遅延で罰）。
- ラベルは**系列全体（=区間）に 1 つ**。部分観測 x_{1:t} からその最終ラベルを早期に当てる。

> この「**1 系列 1 ラベルを、逐次部分観測から、精度と早さを両立して当てる**」構造が、以下の諸問題と共通。

---

## 1. 兄弟問題（何か / どう学習するか）

### (A) 時系列の早期分類（Early Classification of Time Series, ECTS）★最も同型
**何か**：時系列の全体を見る前に、できるだけ早くクラスを確定する。医療（早期診断）、異常検知、
人間行動認識などで「待つほど情報は増えるが判断が遅れる」トレードオフを扱う、専用の研究領域。

**学習ロジック（代表例）**
- **信頼度しきい値型（ECTS, Xing+ 2012 など）**：全長分類器を学習し、「この prefix で予測が以降も
  変わらない最小長（MPL/reliability）」を見積もって停止。停止規則は後付け＋しきい値調整。
- **コスト最適化＋学習型停止（EARLIEST, Hartvigsen+ 2019 など）**：RNN に「停止/継続」を出す
  **halting 方策**を付け、損失 `= 分類損失 + λ·(経過時間コスト)` を最小化。停止は離散なので
  **REINFORCE（方策勾配）**で学習。λ で「早さ vs 精度」の動作点を直接制御。
  → **ユーザが書いた損失（遅延ペナルティ＋早すぎ誤判定ペナルティ）そのもの**。

### (B) 逐次仮説検定 / SPRT（Sequential Probability Ratio Test）★停止規則の理論的支柱
**何か**：サンプルを 1 つずつ観測し、対数尤度比（LLR）を累積、**境界を超えた時点で停止**して判定。
所与の誤り率に対し**期待サンプル数を最小化**するという最適性（Wald）を持つ。

**学習ロジック**
- 古典 SPRT は確率モデルから LLR を計算するだけ（学習不要）。
- **深層 SPRT（例：SPRT-TANDEM, Ebihara+ 2021）**：ニューラルネットで多クラスの LLR を推定し、
  累積が境界を超えたら確定。「早く・正確に」を逐次の証拠累積として実装。
→ 本タスクの SPRT 停止規則（§本手法 5-2）の理論的裏づけ。

### (C) 適応計算時間 / 早期退出（Adaptive Computation Time, Early-Exit）
**何か**：「時間」ではなく**計算の深さ**方向の早期確定。簡単な入力は浅い層で答え、難しい入力だけ深く
処理する（anytime 推論）。
- **ACT (Graves 2016)**：RNN に「あと何ステップ考えるか」を学習させ、**ponder cost**（計算量）を罰に加える。
- **Early-exit ネット（BranchyNet, Teerapittayanon+ 2016 など）**：中間層に分類器を置き、
  **確信度がしきい値を超えたらそこで出力**。
**学習ロジック**：確信度しきい値（後付け）または計算コスト項を損失に加えて学習。
→ 「確信したら即出す」という発想が本タスクと同じ（軸が深さ）。

### (D) 同時通訳 / ストリーミング系列変換（Simultaneous Translation）
**何か**：原文が**途中まで**しか来ていない段階で訳を出し始める。品質（待てば上がる）と
遅延（待つほど悪い）のトレードオフ。
**学習ロジック**
- **固定方策（wait-k, Ma+ 2019）**：k 語遅れて出すと決め打ち。
- **適応方策（monotonic attention / 学習型 read-write, RL）**：「読む（待つ）か書く（出す）か」を
  方策として学習。報酬＝品質 − 遅延ペナルティ。**REINFORCE/微分可能近似**で学習。
→ 「逐次の部分観測から、品質と遅延を両立して出力タイミングを決める」点で本タスクと同型。

### (E) ニューラル・エンドポインティング / 発話終了検出（最も近い「応用」兄弟）
**何か**：ASR で「ユーザが話し終わったか（end-of-utterance / end-of-query）」を判定し、いつ認識を
打ち切るかを決める。**遅延（応答が遅い）vs 早切り（語の途中で切る誤り）**のトレードオフ。
**学習ロジック**：フレーム/トークンごとに「終了か」を二値・系列ラベルで学習（LSTM など）。
早切り誤りに重い罰を与える、あるいは終了確率のしきい値を遅延と精度で調整。
→ **本タスクの直接の親戚**。ただし古典的エンドポインティングは**無音(VAD)依存＝音響主体**。
本タスクは「**意味的完結**」を言語形式から早期に当てる点が違う（無音を待たずに決めたい）。

### (F) ターンテイキング予測 / VAP（対比のため）
**何か**：会話で次に誰が話すか（shift/hold）や発話交替を連続予測する。VAP は将来の音声活動を
**自己教師**で射影して交替を推定。
**本タスクとの違い**：VAP は**音響的に次ターンを射影**する。本タスクは**人手の意味ラベル
（ターン終了/非終了/相槌）を早期分類**する。**ラベルの出所と主手がかり（言語形式）が異なる**。

### (G) 早期異常・早期診断（医療・センサ）
**何か**：敗血症の早期検知などで「発症前にできるだけ早く・誤報なく」警報を出す。
**学習ロジック**：時刻ごとに重み付けした分類損失＋早期発見の報酬／遅延罰。(A) と同じ枠組み。

## 2. 学習ロジックの分類（横断的に 3 系統）

兄弟問題を貫く「どう学習するか」は概ね 3 系統に整理できる。

### 系統① 後付けしきい値（confidence / 連続 / 累積）
各時刻の分類器だけ普通に学習し、**停止は推論時に規則で行う**。
- TEASER 型：確信度 p_max>θ が v 回連続 → 確定。
- SPRT 型：LLR（または top−2nd マージン）を累積 → 境界超で確定。
- しきい値は **dev で sweep**（精度×遅延の動作曲線から運用点を選ぶ）。
- 長所：実装が単純・安定。短所：停止が「学習」されていない（後付け）。

### 系統② 学習型停止方策（halting policy）
「停止/継続」を出すヘッドを置き、**損失に遅延コストを明示**して同時学習。
- 損失 `= 分類損失 + λ·遅延`（＋早すぎ誤判定は分類損失側で罰）。**ユーザの定式化そのもの**。
- 停止は離散なので **REINFORCE / Gumbel-softmax / 微分可能な期待コスト**で最適化（EARLIEST, ACT）。
- 長所：早さ vs 精度を end-to-end で最適化。短所：方策勾配は分散が大きく学習が不安定になりやすい。

### 系統③ prefix 全時刻教師＋時間重み（soft surrogate）
全フレームに「最終ラベル」を broadcast し、**位置に応じた重み**で罰する（終盤ほど重い）。
- 明示的な停止方策を持たず、「早く正しくなるほど得」を**重み**で表現する近似。
- 後付け停止規則（系統①）と組み合わせて運用するのが自然。

## 3. 本手法の位置づけ

| 要素 | 採用している系統 |
|---|---|
| 学習：frame-level cls に**時間重み付き CE** | 系統③（prefix 全時刻教師＋時間重み） |
| 推論：**TEASER / SPRT** で早期確定 | 系統①（後付けしきい値） |
| （未採用）**学習型 halting 方策** | 系統②（＝ユーザ定式化の損失。EARLIEST/ACT 系） |

- 先行の整理 [status_overview §2](turntaking_status_overview.md) の **手法A〜E** は、ちょうどこの分類に対応：
  - A: TEASER（系統①・確信度／学習型 stop_head のハイブリッド）
  - B: ECONOMY（系統②・期待コスト最小化）
  - C: SPRT（系統①・累積）
  - D: RL halting（系統②・方策勾配＝EARLIEST と同型）
  - E: 損失整形（系統③）
- **現状の本手法は ③（時間重み）＋①（TEASER/SPRT）**。ユーザが書いた「遅延罰＋早すぎ誤判定罰」を
  **明示的な学習型停止（系統② / 手法D・EARLIEST 系）**として実装するのが、最も定式化に忠実な次の一手。

## 4. まとめ（一言）

> 本タスク＝**系列の早期分類**（accuracy–latency トレードオフ）。兄弟は ECTS/EARLIEST、SPRT（深層SPRT）、
> ACT・early-exit、同時通訳、ニューラル・エンドポインティング、早期診断など。
> 学習ロジックは ①後付けしきい値 / ②学習型停止方策（遅延コストを損失に明示・RL等）/ ③時間重み prefix 教師
> の 3 系統。ユーザの定式化（遅延罰＋早すぎ誤判定罰）は **系統②**に当たり、文献では **EARLIEST / ACT / 深層SPRT**
> が直接の参考になる。
