## 0. 早期確定とは
現発話を**最後まで聞かず**、フレームが届くたびに区間末タグ（`<継続>`/`<完了>`/`<相槌>`）を推定し、
**十分な確信が得られた時点で確定（halt）**する。目的は**応答遅延の低減**。指標は精度だけでなく
**早さ（earliness＝確定時にどれだけ聞いたか）**も含む。停止方策が「今確定 or 待つ」を各時刻で決める。

```
時間 →   t1   t2   t3   ...   tk (確定) ................ 発話末
        p_t1 p_t2 p_t3 ...   p_tk
                              └─ halting policy が「確定」と判断 → ここでタグ確定
        （tk 以降のフレームは聞かない＝早期確定）
```

- **速い＝早い時刻で確定（情報少・精度落ちやすい）／遅い＝末尾近くで確定（情報多・精度高い）**。
- 3手法は「**いつ halt するか**」の判断ルールが違うだけ。土台（下記§1）は共通。

---

## 1. 共通の土台：ストリーミング逐次予測ヘッド
既存の Contextual Block Conformer は**ブロック単位のストリーミング**（block_size=18, hop=3, look_ahead=3）。
これを活かし、**各ブロック t までの encoder 出力から、その時点の区間末タグ確率 p_t を出す**。

```
  現発話音声（ストリーミング）
        │  ブロックごとに encoder 出力が伸びる
   共有エンコーダ（Contextual Block Conformer）──► Transducer → テキスト（ASR・不変）
        │
        │  各時刻 t で encoder出力[:t] を pooling（末尾ブロック or 累積平均）
        │        （+ 過去文脈 ctx_vec を concat／§文脈手法）
        ▼
   逐次ヘッド MLP → p_t = softmax(継続, 完了, 相槌)   ← 時刻ごとに1本
        │
        ▼
   停止方策（SPRT / TEASER / ECONOMY）← ここが手法差
        │
        ▼
   確定タグ ŷ と 確定時刻 t*（earliness）
```

### 逐次ヘッドの学習（全手法共通）
- 各時刻 t の p_t を、**その発話の最終タグ y（区間末で定義）**で教師付け（deep supervision）。
  `L_tag = Σ_t w_t · CE(p_t, y)`（w_t は時刻重み。末尾ほど確実なので後半を重くしてもよい）。
- 全時刻を使うと重いので、**数個のプレフィックス長 t∈{s_1..s_S} をサンプリング**して学習（TEASER の snapshot と同じ発想）。
- 総損失 `L = L_ASR + α·L_tag`（ASR は現発話のみで不変）。
- **停止方策は推論時に載せる**（SPRT/TEASER/ECONOMY）。学習で確率列 {p_t} を良くしておけば、方策は差し替え可能。

---

## 2. 手法A：SPRT（逐次確率比検定）
Wald の逐次検定。仮説（＝各クラス）に対し、**尤度比（対数尤度比 LLR）を時刻とともに累積**し、
**閾値を超えたら確定**。誤り率(α,β)から閾値が決まり、**同じ精度なら期待停止時刻を最小化**（最適性）。

### 仕組み（多クラス＝MSPRT）
- 各時刻 t で、クラス k の他クラスに対する累積 LLR
  `Λ_t(k) = Σ_{τ≤t} [ log p_τ(k) − log max_{j≠k} p_τ(j) ]`（近似）。
- `max_k Λ_t(k) ≥ A`（閾値）になったら、その k で**確定**。閾値 A で早さ/精度を調整。
- **深層版 SPRT-TANDEM**（Miyagawa & Ebihara）：ネットワークが LLR を直接推定するよう学習
  （multiplet 損失で「累積が正しい LLR になる」ように）。softmax からの近似でも動く。

```
 累積LLR  Λ_t(完了) ────────────────╱──── A（上側閾値）→ ここで「完了」確定
                              ╱
                   ╲___╱
 Λ_t(継続) ─────────────────────────  （閾値未達＝まだ待つ）
```

### 実装要点
- 逐次ヘッドの p_t から Λ_t を累積するモジュール（推論時）。閾値 A を dev で earliness/精度から選ぶ。
- SPRT-TANDEM を厳密にやるなら、ヘッドを「LLR 出力＋multiplet 損失」に変更。

## 3. 手法B：TEASER（二段構え：予測＋信頼判定、v回連続で確定）
各プレフィックス長で「①クラス予測」と「②その予測が信頼できるか」を別々に持ち、
**②が v 回連続で"信頼できる"となったら確定**。早すぎる fluke 確定を防ぐ。

### 仕組み
- **①予測器**：各 snapshot s の p_s（§1のヘッド）。予測クラス ŷ_s = argmax p_s。
- **②信頼判定器**：snapshot s ごとに **one-class 分類器（例 one-class SVM）** を、
  **学習データで正解した時の確率ベクトル p_s** で訓練。テスト時、p_s が「信頼圏内」なら accept。
- **停止規則**：accept が **v 回連続**したら、その予測を確定（v は dev で earliness×精度の調和平均を最大化するよう調整）。

```
 snapshot: s1  s2  s3  s4  s5 ...
 予測ŷ_s :  完  完  完  完  完
 信頼判定:  ✗   ✓   ✓   ✓(v=3で確定)  ...
                    └───v=3連続──┘→ ここで「完了」確定
```

### 実装要点
- ①は§1の逐次ヘッド。②は sklearn one-class SVM を snapshot ごとに fit（学習後に別途）。
- 推論：各 s で p_s → SVM accept/reject → v 連続で halt。v と snapshot 集合が主ハイパラ。
- 注：TEASER 原著は「各切断長の分類器＋one-class の master」。名称より**「予測＋信頼の二段＋v連続」**が本質。

## 4. 手法C：ECONOMY（コスト最小の非近視眼的停止）
**誤分類コスト＋遅延コスト**の**期待総コストが最小**になる時刻で確定。将来を見越して（非近視眼的）、
「今確定」と「待って後で確定」の期待コストを比較する。

### 仕組み
- コスト定義：`Cost = C_miss(ŷ, y) + C_delay(t)`。C_delay(t) は t の増加関数（遅いほど損）。
  C_miss は混同のコスト（例：`<完了>`を`<継続>`と誤ると応答が遅れる、等をコスト行列で表現）。
- 各時刻 t で、**「今止めた時の期待コスト」と「もう1ステップ待った時の期待コスト」を推定**し、
  待つ方が高くなったら**確定**（最適停止）。
- 将来推定は、学習系列を**クラスタリング（K個）**して「クラスタごとの確信度の時間推移」を持ち、
  現発話がどのクラスタに近いかで将来の p_t を予測（ECONOMY-γ / Dachraoui 2015, Achenchabe 2021）。

```
 期待総コスト
   待つ場合 ┐          ╱  ← 待つほど遅延コスト増（かつ精度改善は頭打ち）
           └────╲____╱
   今止める場合 ─────●──── ← ここで「今止める≦待つ」→ 確定（コスト最小点）
                    t*
```

### 実装要点
- コスト行列 C_miss と遅延コスト C_delay(t) を設計（応用要件から）。
- 将来確信度の推定器：uvec 等でクラスタリング → クラスタ別の p_t 推移表を学習データで作る。
- 推論：各 t で期待コストを比較して halt。**コスト設計が結果を大きく左右**（要チューニング）。

## 5. 統一アーキテクチャ（停止方策を差し替え可能に）
```
 現発話音声（ストリーミング）
      │
 共有エンコーダ（Contextual Block Conformer）──► Transducer → テキスト（ASR・不変）
      │
      │ 各時刻 t: encoder出力[:t] を pooling (+ctx_vec)
      ▼
 逐次ヘッド MLP → 確率列 {p_t}
      │
      ▼
 ┌─────────────── 停止方策（プラガブル）───────────────┐
 │  A. SPRT   : 累積LLR が閾値 A を超えたら確定           │
 │  B. TEASER : 信頼判定が v 回連続 accept で確定          │
 │  C. ECONOMY: 期待総コスト最小の時刻で確定             │
 └─────────────────────────────────────────────────────┘
      │
      ▼
  確定タグ ŷ ＋ 確定時刻 t*（earliness）
```
- **学習は共通**（逐次ヘッドで {p_t} を良くする）。**停止方策は推論時に載せ替え**て3手法を比較。
- **過去文脈 ctx_vec は各時刻に注入可**：早期は情報が少ないので、過去文脈が「事前分布」として効き、
  **早期確定の精度を底上げ**する狙い（＝これまでの文脈手法と早期確定の融合）。

## 6. 評価指標
- **精度**：確定タグの acc / macro-F1 / クラス別（従来どおり）。
- **早さ（earliness）**：確定時刻 t* / 発話長（小さいほど早い）。
- **総合**：earliness と精度の**調和平均（TEASER の HM）**、または ECONOMY のコスト。
- 停止方策ごと（SPRT/TEASER/ECONOMY）に**精度 vs 早さ曲線**を描いて比較。

## 7. 実装計画（既存への追加）
1. `espnet_model_turntaking.py`：逐次ヘッド（各時刻 t の p_t）＋deep supervision 損失を追加
   （`per_step_head=True`, プレフィックス集合 S）。学習は既存パイプラインで。
2. 推論・停止方策は**別モジュール** `local/turntaking/halting.py`（SPRT / TEASER / ECONOMY を実装、{p_t}→(ŷ,t*)）。
3. 評価 `evaluate_multitask.py` に **streaming 評価**（{p_t} を出す）＋ earliness 指標を追加。
4. TEASER の one-class / ECONOMY のクラスタは**学習後に別途 fit**（軽い後処理）。SPRT は閾値のみ。
