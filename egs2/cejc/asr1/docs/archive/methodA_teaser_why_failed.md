# なぜ Method A (CIF-TEASER) で no/yes が改善しなかったか — 総括資料

作成日: 2026-06-12
対象: `egs2/cejc/asr1` / CIF-TEASER（slave=tag_classifier, master=stop_head）
タスク: 発話区間末検出　`<no>`=区間末でない / `<yes>`=区間末である / `<other>`=相槌
詳細な実験ログ: [methodA_teaser_diagnosis.md](methodA_teaser_diagnosis.md)（証拠の全数値）

> この資料は「何を試して、どこが改善せず、なぜダメだったか」を、
> **診断手法の妥当性と限界も含めて**まとめたもの。

---

## 1. 要約（結論）

> **2026-06-12 追記で結論を訂正**。当初の「0.62 が streaming の構造的上限」は誤り。
> 正しくは **セグメント化 + 遅延0 の即決** のアーティファクト。詳細 §9。

- 根本原因は表現力不足ではなく**情報不足**：区間末判定の決定打である
  「発話直後の無音・次話者ターン」は **(a) セグメント化で切り落とされ**、(b) 区間末で即決（遅延0）
  していたため使えなかった。
- **訂正（§9）**：因果性を保ったまま**区間末より先を観測（=エンドポイント遅延）**すれば、
  no/yes 分離は **0.62（0ms）→ 0.68（800ms）→ 0.70（1200ms）** と単調に上がる。
  情報は元録音（セグメント間ギャップ）に残っており復元可能。これは未来の先読み（acausal）
  ではなく「待つ」こと＝標準的 VAD エンドポイント遅延。
- encoder の look_ahead=9 フレーム≈300ms **だけでは不十分**（Δ=300 でほぼ動かない）。
  決定打は区間末直後 300ms ではなく **500–1200ms 先の無音/次ターン**にある。
- `<other>`（相槌）は長さで完結する手がかりがあるため F1 0.93 で解ける。
- **問題の本質は「精度 vs 遅延」のトレードオフ**であり、これを最適化する SPRT / ECONOMY と相性が良い。
- **限界**：利得は有界（1200ms でも ~0.70、0.9 ではない）。frozen 線形プローブの下限的見積りで、
  trailing 文脈で再学習すればさらに上がる余地あり（§6・§9）。

## 2. 手法（何を解こうとしたか）

CIF で音響をトークン単位 fire に積算し、各 fire で
- **slave: tag_classifier**（cif_out[i] → no/yes/other の確率 p_i）
- **master: stop_head**（φ_i → 停止確率）で「いつ確定するか」を学習（TEASER 2段階）。

φ_i = [sort(p_i)(3), margin(1), entropy(1), 位置(1), cif_proj(16)] = 22次元。
停止条件: stop_prob > 閾値 かつ 同クラス v 回連続。dev で (閾値, v) を sweep。

| `<other>` | 0.928 | 0.926 | （容易）|

全体 acc 0.733 / macro F1 0.679。**no/yes 境界が崩壊**。

## 4. 試したことと結果（一覧）

| # | 試した施策 | 狙い | 結果 |
|---|---|---|---|
| 1 | **クラス重み** `[1.92,1.00,1.63]` | `<no>` の流出抑制 | 動作点が滑るだけ。macro F1 不変（0.69）。`<no>`→`<yes>` が減る代わりに `<yes>`→`<no>` 増 |

| 4 | **dev sweep**（閾値×v）| 最良動作点探索 | 最低閾値 0.3 が最良＝stop_prob のダイナミックレンジが死んでいる症状 |

→ slave 側（表現・文脈）も master 側（stop_head）も改善せず。

## 5. なぜダメだったか（根本原因）

### 5.1 slave（tag_classifier）：情報が無い
- cif_out も encoder_out も、no/yes を線形/非線形いずれでも **~0.62 までしか分離できない**。
- encoder は train で tag loss も逆伝播して学習済み。**「分離するチャンスを与えられた上で」0.62**。
  → セグメント内音響に no/yes 情報がそもそも乏しい。
- 区間末の決定打＝**発話直後の無音/次ターン**は、(a) セグメントが語末で切られ存在しない（末尾無音0ms）、
  (b) 未来＝streaming で禁止。**二重に使えない**。
- 過去文脈（自話者/相手の直前発話）も frozen 特徴では効かなかった。

### 5.2 master（stop_head）：教師信号が矛盾
- `stop_target` は「分類が正解か（＝隠れ正解 y に依存）」で定義されるが、入力 φ には y を
  判定する材料が無い（sort 済み確率は**クラス非依存**、cif_proj は slave と同じ no/yes 盲点）。
- 結果、自信満々で外す `<no>` の fire と自信満々で当てる `<yes>` の fire が φ 上ほぼ同一なのに
  target は 0/1 と矛盾 → head は周辺分布（pos_ratio 0.65）しか学べず stop_acc 0.76 で飽和。
- これは slave が弱い（5.1）ことの**下流的帰結**でもある。slave が直らない限り master も直らない。

### 5.3 構造的な緊張
- **「区間末検出」と「streaming 早期確定」は本質的に相性が悪い**。
  末を当てる最強手がかりが未来にあるのに、未来を禁じているため、因果的には決められない。
  0.62 はこの構造的限界の反映。

## 6. 診断手法の妥当性と限界（重要）

本総括の根拠は主に **学習済み encoder の frozen 特徴に対する線形/MLP プローブ（dev）**。
その妥当性と限界を明示する。

**妥当な点（断定してよい）:**
- 再表現（GRU 等）の棄却：causal-mean/encoder/非線形/結合がすべて 0.62 前後 → 再表現で増える情報は無い。
- セグメント内音響の上限 ~0.62：encoder は train で tag loss 込みで学習済みのため、frozen でも実質上限を表す。
- 「末尾無音 0ms」「未来禁止」は**プローブに依らないデータ/制約の事実**。学習しても変わらない。

**限界（断定できない）:**
- **frozen 特徴＋線形プローブ**であり、end-to-end 学習は行っていない。特に C-3（過去文脈）は
  直前区間の cif_mean を連結しただけなので、**文脈を使うよう学習した専用モデルや、テキスト（統語）
  ベースのモデル**なら改善する可能性を**否定しきれない**（示唆であって証明ではない）。
- プローブは dev のみ。train 全体で学習した分類器の厳密な上限とは一致しない可能性（ただし
  encoder 自体は train 済みなので大きくは動かないと考えられる）。

**定義的に確かめるには（未実施）:**
- §7 の 1・3 を実際に **train で end-to-end 学習**して dev/test 評価する必要がある。
  本診断はその前段の「安い screen」であり、**明らかに無駄な再学習（GRU 等）を回避する**目的は達成した。

## 9. 【結論訂正】trailing 文脈プローブ（2026-06-12）

§5 までの「0.62 上限」は **タイトに切られたセグメントを encoder に通していた**ことの帰結だった。
元録音（フルセッション）と `segments`（秒単位 start/end）が残っており、区間末直後の無音は
**セグメント間ギャップ**として物理的に存在する（例: 区間末 97.609 → 次区間 98.148 の間 539ms）。

### 検証
frozen v2 stage1 のまま、各 no/yes 区間を `[start, end+Δ]` で読み直し、区間末以降の
encoder 表現で線形プローブ。`local/diagnose_trailing_context.py`。

| Δ（区間末からの追加観測）| enc_at_end | **enc_lastk** | cif_last |
|---:|---:|---:|---:|
| 0 ms（タイト切り）| 0.606 | 0.618 | 0.623 |
| 300 ms（look_ahead 相当）| 0.603 | 0.626 | 0.615 |
| 500 ms | 0.614 | 0.645 | 0.646 |
| 800 ms | 0.665 | 0.681 | 0.678 |
| 1200 ms | 0.655 | **0.705** | 0.677 |

### 解釈
- no/yes 分離は **区間末より先の観測時間の単調増加関数**（0.62 → 0.70）。
- **因果的**：時刻=区間末+Δ に立ち、そこまでの音声のみ使用。未来の先読みではなく
  「エンドポイント遅延を延ばす」こと。streaming 制約に違反しない。
- encoder の look_ahead=300ms **だけでは不足**（Δ=300 で 0.626）。決定打は 500–1200ms 先にある。
- 利得は有界（1200ms で ~0.70）。会話のターン交替は本質的に曖昧で無音だけでは決まらない残差がある。
- frozen 線形プローブのため**下限的見積り**。trailing 文脈で再学習すれば上振れの余地。

### 改善方針（§6 を更新）
1. **再セグメント化（最優先・データ修正）**：各セグメント end を `+区間末ギャップ（〜800–1200ms 打ち切り）`
   に延長 → slave が無音/次ターンを観測可能に。アーキ変更不要、追加は因果的遅延のみ。
2. **slave ストリームを trailing 領域へ延長**：CIF は最終語で発火が止まるため、末尾フレームの
   encoder pool（enc_lastk）や明示的 pause/VAD/energy 特徴を tag 入力に追加。
3. **SPRT / ECONOMY で per-utterance 適応遅延**：明確な yes は早期確定、曖昧な no は無音を待つ。
   上表が各遅延での到達精度＝動作曲線。固定閾値 TEASER より本質的に良い当てはまり。

→ 次の具体ステップ: **再セグメント化 → stage1 再学習 → tag 指標と本プローブで効果確認**。
