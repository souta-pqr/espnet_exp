# 新しいタグ（Qwen3-8B）の付与精度：Claude と同条件で比べる（2026-10-07）

対象: docs/plan.md ⓪-1・⑥。新しい分割の `tag` は Qwen3-8B full_context/oneshot の出力をそのまま使っている。
その精度を人手正解 1000 件で測り、同じ条件で Claude（Opus 5.5）が付けた場合と比べた。

## 条件（Qwen と同じ）

ラベル付けの手順は `full_context/detect_section_text.py`（`~/work/cejc-label` と同一）と同じ:
1. 中身が相槌の一覧に入る → 相槌（ルール）
2. 直後に話し始めるのが別の話者 → 完了（ルール。人手正解 1000 件のうち 78 件。両者同じ）
3. それ以外を LLM が「はい／いいえ」で判定（922 件）

3 のプロンプトは `/autofs/diamond5/share/users/kobori/full_context/oneshot/prompt_{system,user}.txt`。
入力（直前 10・後続 10 発話、重複タグ、ポーズ行、同話者継続間隔）は Qwen の結果ファイルに残る文脈から
同じ描画関数で作り直した（`local/turntaking/gold1000_prompts.py`。対象発話は gold.txt と 1000/1000 一致）。

Claude の判定は 10 組（93 件ずつ）に分け、組ごとに独立したエージェントが付けた。入力には人手正解も
Qwen の判定も含めていない。**Qwen と違う点**：1 件ずつ別に推論したのではなく、指示と例を 1 回読んだあと
93 件を続けて判定している。

## 結果（完了 / 継続の 2 値）

人手正解との一致（左＝標本そのまま／右＝母集団の比率で重み付け）:

| | 一致率 | 継続 F1 | 完了 F1 | macro-F1 |
|---|---|---|---|---|
| **Qwen3-8B（＝新しい tag）** | 0.764 / **0.773** | 0.701 / **0.629** | 0.805 / 0.837 | 0.753 / **0.733** |
| Claude | 0.796 / **0.796** | 0.785 / **0.688** | 0.806 / 0.848 | 0.795 / **0.768** |

LLM が判定した 922 件だけでは Qwen 0.762 → Claude 0.797（差 +0.035、95% 信頼区間 −0.003〜+0.072）。
判定が割れた 312 件で人手に合っていたのは Claude 172 件・Qwen 140 件（McNemar p = 0.079）。

| | 完了 | 継続 |
|---|---|---|
| 人手 | 509 | 413 |
| Qwen | 562 | 360 |
| Claude | 402 | 520 |

**Claude と Qwen の一致は 0.662（κ 0.34）と低い。** 重み付けで 0.689（κ 0.37）。

## 読み取り

1. **新しい tag（Qwen）の精度は、相槌を除く全区間で一致率 0.77・継続 F1 0.63 程度。** 9/30 の推定（0.748・0.604）と同水準。
2. **Claude は継続の判定で明確に上（継続 F1 +0.06〜0.08）。完了はほぼ同じ。** 全体では +0.02〜0.03 だが、
   有意水準 5% には届かない（p = 0.08）。
3. **Qwen は完了寄り、Claude は継続寄りに偏る。** 人手の比率はその中間。Qwen が完了と言い Claude が継続と言った
   236 件は人手で半々（118 / 118）。この型の区間はどちらのモデルにも難しい。
4. **2 つの LLM の一致が κ 0.34 しかない。** 区間末かどうかは LLM どうしでも大きく割れる。
   「ラベル自体が定まらない区間が多い」（docs/report_20260928_accuracy_speed.md）と整合する。

## 注意

- 人手正解の標本は、Qwen を含む 8 条件の LLM 判定でプールを分けて抜いたもの。重み付けは層（経路 × Qwen の判定）での近似。
- 人手のアノテータが付与時に LLM の判定を見ていたかは未確認（抽出スクリプトは注釈用ファイルに「モデル判定」を書き出している）。
  見ていたなら Qwen 側に有利な偏りになる。
- Claude はプロンプトを 1 件ずつではなく 93 件まとめて処理しているので、厳密な同一条件ではない。
